Rules

  1. Indicator: ZigZag++ [LD] (DevLucem, MT4-style) on 1h candles, Depth 12, Deviation 5, Backstep 2. Labels HH/HL/LH/LL compare each pivot with the previous pivot of the same kind.
  2. Setup: two consecutive swing lows that are both LL, with the swing high between them. L1 = first LL, L2 = second LL, H = swing high between.
  3. A swing pivot is used only from the bar where ZigZag++ flips direction (pivot confirmed); no lookahead. Typical lag 4–13 bars.
  4. Entry (long only): after L2 is confirmed, the first GREEN 1h candle (close > open) that crosses above L1: close > L1 and (open ≤ L1 or previous close ≤ L1). Buy-stop at that candle's high, filled on the next bar if it trades that high; otherwise the trade is skipped.
  5. No correction before entry: the trigger must come straight after L2 is confirmed. If ZigZag++ confirms any new swing pivot after L2 (e.g. a lower high then a higher low) before the trigger candle closes, the setup is discarded. Only pivots confirmed by the trigger bar are used (no lookahead).
  6. Stop: L2 (just below the second LL). Target: H. If stop and target hit in the same bar, the stop is assumed.
  7. Filter: take the setup only if reward/risk (H − entry) ÷ (entry − L2) ≥ 1.5 AND the last completed daily close is above the daily EMA 50; otherwise the setup is dropped.
  8. Cost 0.1% per trade. One trade at a time per pair. Setup skipped if entry ≥ H or ≤ stop, or if price falls to L2 before the breakout.
