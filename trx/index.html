Strategy rules

SELL setup

  1. Renko brick flips green → red
  2. Hull Suite 55 is still red
  3. MACD histogram goes dark green → light green or light red → dark red

BUY setup

  1. Renko brick flips red → green
  2. Hull Suite 55 is still green
  3. MACD histogram goes dark red → light red or light green → dark green

Hull colour = Hull value vs its value 2 bricks back (rising = green, falling = red). Histogram shade: above zero, dark green if rising / light green if falling; below zero, dark red if falling / light red if rising. "Before" is the brick before the flip, "after" is the flip brick.
